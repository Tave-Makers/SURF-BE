## 계정 통합 대상 조회

### 개요

온보딩 중 이미 가입된 계정이 감지된 사용자가 통합 대상의 프로필과 연결된 소셜 로그인 수단을 확인하는 API입니다.

임시 회원의 Access Token으로 대기 중인 계정 통합 정보를 조회하며, 조회만으로 통합 대기 정보가 삭제되거나 만료 시간이 연장되지는 않습니다. 실제 계정 통합은 별도의 통합 확정 API를 통해 수행합니다.

### 📌 엔드포인트

`GET /v1/user/social-accounts/integrate/target`

### 🔐 인증

- **인증 필요 여부:** JWT 인증 필요
- **인증 주체:** 계정 통합 안내를 받은 `REGISTERING` 상태의 임시 회원

> 요청 헤더(Header)에 아래와 같이 Authorization 필드를 포함해야 합니다.
>
> `Authorization: Bearer {JWT_TOKEN}`

### ▶️ 요청 (Request)

<aside>

### Headers

| Key | Type | 설명 | 필수 |
| --- | --- | --- | --- |
| `Authorization` | String | 임시 회원의 Access Token. `Bearer {JWT_TOKEN}` 형식 | ✅ |

### Path Parameters

없음

### Query Parameters

없음

### Body

요청 본문 없음

### ▶️요청 예시

```http
GET /v1/user/social-accounts/integrate/target HTTP/1.1
Authorization: Bearer {JWT_TOKEN}
```

</aside>

### ◀️ 응답 (Response)

<aside>

### 성공 (Success)

| HTTP Status | 의미 |
| --- | --- |
| `200 OK` | 계정 통합 대상 조회 성공 |

**Body**

| Key | Type | 설명 |
| --- | --- | --- |
| `code` | int | HTTP 상태 코드 |
| `message` | String | 응답 메시지 |
| `data` | Object | 계정 통합 대상 정보 |
| `data.providers` | String[] | 통합 대상에 연결된 소셜 로그인 제공자 목록. `KAKAO`, `APPLE` 중 하나 이상 |
| `data.email` | String | 사용자가 온보딩에 입력한 이메일 |
| `data.phoneNumber` | String | 사용자가 온보딩에 입력한 전화번호 |
| `data.username` | String | 통합 대상 회원 이름 |
| `data.profileImageUrl` | String \| null | 통합 대상 프로필 이미지 URL |
| `data.trackList` | Track[] | 통합 대상 트랙 목록. 트랙이 없으면 빈 배열 |
| `data.trackList[].generation` | int | 활동 기수 |
| `data.trackList[].part` | String | 활동 파트. 예: `BACKEND`, `WEB_FRONTEND` |
| `data.selfIntroduction` | String \| null | 통합 대상 자기소개 |

### 응답 예시

```json
{
  "code": 200,
```

### 실패 (Error)

<aside>

| HTTP Status | 의미 | 에러 코드 |
| --- | --- | --- |
| `401 Unauthorized` | Access Token이 유효하지 않거나 만료됨 | `UNAUTHORIZED` |
| `403 Forbidden` | 요청한 회원에게 API 접근 권한이 없음 | `ACCESS_DENIED` |
| `404 Not Found` | 통합 대기 정보가 없거나 이미 사용되어 무효화됨 | `INTEGRATION_TOKEN_NOT_FOUND` |
| `404 Not Found` | 통합 대상 회원이 존재하지 않음 | `MEMBER_NOT_FOUND` |
| `409 Conflict` | 임시 회원 상태, 소셜 계정 소유권, 대상 상태 또는 연락처 등 계정 통합 조건을 충족하지 않음 | `INTEGRATION_NOT_ELIGIBLE` |
| `410 Gone` | 계정 통합 대기 정보가 만료됨 | `INTEGRATION_TOKEN_EXPIRED` |

> 에러 코드 열은 서버 내부 예외 식별자입니다. 현재 공통 실패 응답 본문에는 문자열 에러 코드가 포함되지 않으며 `code`, `message`, `data`를 반환합니다.

**응답 예시 (401 Unauthorized)**

```json
{
  "message": "Invalid or expired access token"
}
```

**응답 예시 (404 Not Found)**

```json
{
  "code": 404,
  "message": "유효하지 않은 [통합 토큰]입니다.",
  "data": null
}
```

**응답 예시 (409 Conflict)**

```json
{
  "code": 409,
  "message": "계정 통합 조건을 충족하지 않습니다.",
  "data": null
}
```

**응답 예시 (410 Gone)**

```json
{
  "code": 410,
  "message": "만료된 [통합 토큰]입니다. 통합을 다시 시작해주세요.",
  "data": null
}
```

</aside>
